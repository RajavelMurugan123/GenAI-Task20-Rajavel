
# Assignment 20: Movie Recommendation System

## Project Overview
A content-based movie recommendation system using Python,
Pandas, Scikit-learn, TF-IDF and cosine similarity.

## Dataset
TMDB 5000 Movie Dataset

Kaggle:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit
- Git and GitHub
- Render

## Project Structure

GenAI-Task20-Rajavel/
- app.py
- recommender.py
- requirements.txt
- README.md
- .gitignore
- data/tmdb_5000_movies.csv

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Machine Learning Workflow

1. Dataset loading
2. Data exploration
3. Text preprocessing
4. TF-IDF vectorization
5. Cosine similarity
6. Recommendation generation
7. Streamlit deployment
